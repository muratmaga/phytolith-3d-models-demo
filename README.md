# Phytolith 3D models (demo)

Demonstration set for the Strömberg lab (UW Biology / Burke Museum paleobotany). Grass phytoliths (silica bodies about 20 micrometres long) imaged by confocal microscopy after fluorescent staining, segmented by hand in Fiji, meshed and decimated to 20 000 faces in MeshLab, and aligned for 3D geometric morphometrics (landmarks and surface semilandmarks placed in Checkpoint). Two example models provided by Caroline Strömberg. Coordinates are in micrometres. Demo only; not for citation.
